# 🚀 Structure-Architect v1.31

**〜 誰でも、どこでも、直感的に。Webサイト構築を加速させる万能型WYSIWYGエディタ 〜**

## 🌟 プロジェクト・マニフェスト

「コードの壁を、創造性の翼に。」

Structure-Architectは、HTMLの専門知識がなくても、積み木を組むようにWebサイトを構築できるフリー・オープンソースのエディタです。
既存の複雑なHTMLとの互換性を保ちつつ、直感的な操作でプロフェッショナルなレイアウトを実現することを目指しています。

### 🛠 主な特徴

- **Isolation Sync システム**: 読み込んだCSSをエディタUIから隔離。デザインを壊さず編集可能。
- **全機能搭載ツールバー**: 見出し、2カラム、YouTube埋め込み、テーブル挿入を1クリックで。
- **インテリジェント・プロパティ**: 文字色、余白、背景色をリアルタイム調整。
- **双方向同期**: デザイン画面とソースコードをいつでもスイッチ可能。

### 🤝 自由への約束

このツールは、誰でも無料で利用、改良、再配布が可能です。
Webサイト制作をもっと自由に、もっと楽しく。あなたの手で、このツールをさらに進化させてください。
